# Responsive Tea House Website

This project is a fully responsive static website built for practice purposes using Tailwind CSS.
The design represents a modern tea shop landing page called “Tea House” with multiple sections including hero, featured products, testimonials, news & events, and a footer.

The main goal of this project was to practice responsive layouts, Tailwind utility classes, gradients, flexbox, grid system, and component-based section structuring without using any JavaScript framework.

### Technologies Used  
• HTML5  
• Tailwind CSS (CDN version)  
• Font Awesome (for icons)  
• Responsive Design (Mobile, Tablet, Desktop)

---

### Features  
• Fully responsive layout for all screen sizes  
• Clean and modern UI design  
• Tailwind CSS utility-first styling  
• Gradient buttons and backgrounds  
• Grid and flexbox based sections  
• Testimonial cards with layered layout  
• News & events section with responsive cards  
• Footer with newsletter subscription UI and social icons

---

### Project Sections Overview

#### 1. Hero Section

* Large heading with gradient button
* Banner image
* Rating popup card

#### 2. Featured Products

* Responsive grid layout
* Product cards with images and descriptions

#### 3. About / Presentation Section

* Image grid layout
* Text content describing quality and uniqueness

#### 4. Testimonials Section

* Gradient background
* Client review cards with overlapping design

#### 5. News & Events

* Responsive card layout
* Image, date, title, description

#### 6. Footer

* Call-to-action area
* Quick links and services
* Newsletter subscription input
* Social media icons
